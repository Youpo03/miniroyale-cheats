# ГЛУХОМАНЬ — генератор хоррор-шортсов для TikTok

Код собирает вертикальные ролики 1080×1920 «под ключ»: рисует 2D-анимацию,
озвучивает текст, синтезирует музыку и звуки, накладывает субтитры
и сводит всё в MP4, готовый к загрузке. Чужой музыки и картинок нет:
всё генерируется с нуля, поэтому TikTok не глушит звук.

Ролики канала:

| Серия | Файлы | Длина |
|---|---|---|
| ep1 «Третий стук», часть 1 | `ep1_story.py`, `ep1_render.py`, `ep1_audio.py` | 84 с |

## Быстрый старт

```bash
bash setup.sh             # зависимости, голоса Piper, шрифты
python3 build.py ep1      # → out/ep1.mp4
```

Нужны Python 3.11+, `ffmpeg` с фильтром `rubberband` и около 2 ГБ места под модели.
Полная сборка серии на 4 ядрах занимает 7–10 минут.

Полезные режимы:

```bash
python3 build.py ep1 --stills 0,12.5,44.6   # только кадры-превью в build/ep1/stills/
python3 build.py ep1 --from audio           # пересобрать звук и видео, не трогая озвучку
```

## Как устроена сборка

1. **Озвучка** (`tts.py`). Реплики синтезируются голосами Piper: рассказчик — `ruslan`,
   бабушка — `irina`. Каждая реплика делается в 4 дублях; каждый дубль распознаётся
   Whisper, и выбирается тот, где распознанный текст совпал со сценарием. Так отсеиваются
   неразборчивые дубли. Для голоса «за дверью», шёпота и т. п. есть своя обработка (`process`).
   Неверные ударения правятся сырыми фонемами в `PRON_FIX`, например `[[bʲɪs]] связи`.
   Готовые дубли кэшируются в `build/<ep>/voice_cache`.
2. **Таймлайн** (`timeline.py`). Из выравнивания фонем получаются тайминги каждого слова,
   поэтому субтитры идут синхронно с голосом по 1–4 слова. Также рассчитываются сцены и метки событий.
3. **Звук** (`sfx.py` + `epN_audio.py`). Стуки, скрипы, ходики, сверчки, гул, шкатулка
   и сердцебиение синтезируются кодом. Музыка приглушается под голос, громкость выравнивается до −14 LUFS.
4. **Кадры** (`common.py` + `epN_render.py`). Рисование на skia: персонажи (`chars.py`),
   изба и деревня (`world.py`), свет через карту освещения, камера, субтитры, HUD.
   Рендер идёт в несколько процессов, потом куски склеиваются.

## Как сделать новую серию

1. Скопируйте `ep1_story.py` в `ep2_story.py` и напишите сценарий битами:
   `line` (реплика), `sfx` (звук), `pause`. В тексте `*звёздочки*` делают слово
   красным в субтитрах, `scene` задаёт сцену.
2. Опишите сцены в `ep2_render.py`: функции `sc_<сцена>(cv, t, s)`, регистрация в `common.SCENE_FN`
   и позиции субтитров в `common.CAP_Y`.
3. Опишите звук в `ep2_audio.py`. Удобно взять за основу `ep1_audio.py`.
4. Запустите `python3 build.py ep2`.
