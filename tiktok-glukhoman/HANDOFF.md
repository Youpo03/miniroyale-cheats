# Передача проекта в новую сессию

## 1. Что вставить в новую сессию Claude Code (на ПК)

Откройте эту папку в Claude Code (приложение или `claude` в терминале) и отправьте:

> Продолжаем проект TikTok-канала «ГЛУХОМАНЬ»: это генератор анимированных хоррор-шортсов на Python.
> Прочитай `HANDOFF.md`, `README.md` и `CHANNEL.md` в этой папке.
> 1. Установи окружение: на Windows `setup.ps1`, на Mac/Linux `setup.sh`. Проверь, что кадры рисуются:
>    `python build.py ep1 --stills 1.25,44.6`.
> 2. Доделай серию 2 «Пугало»: напиши `ep2_audio.py` по плану звука из раздела 5 HANDOFF.md
>    (основа — `ep1_audio.py`, нужные звуки уже есть в `sfx.py`) и собери `python build.py ep2 --from audio`.
> 3. Проверь результат: контактный лист кадров, распознавание речи Whisper по готовому звуку, громкость −14 LUFS.
>    Потом пришли мне готовое видео `out/ep2.mp4`.
> 4. Сделай аватарку канала `assets/avatar.png` (1080×1080) в стиле канала.
> Озвучка обеих серий уже готова и проверена, `tts.py` переиспользует её автоматически.
> Не перегенерируй её (`--fresh`) без необходимости.

## 3. Что где лежит

- `ep1_story.py`, `ep2_story.py` — сценарии (биты: реплика / звук / пауза, `*слово*` — красное в субтитрах).
- `tts.py` — озвучка Piper. Каждая реплика синтезируется в 4 дублях, Whisper выбирает самый разборчивый,
  неверные ударения правятся через `PRON_FIX`. Готовая озвучка переиспользуется, если текст не менялся.
- `timeline.py` — тайминги, сцены, метки (`cues`), субтитры по 1–4 слова.
- `sfx.py` — библиотека звуков: стук, скрип, ходики, сверчки, ветер, гул, шкатулка, сердцебиение,
  ворона, птицы, шорох соломы, писк записи, глитч, шум камеры, перемотка, микшер `Mix` и `finish()`.
- `ep1_audio.py` — звуковой дизайн серии 1 (образец для серии 2).
- `common.py` — общий рендер: камера, свет, субтитры, HUD, изба, кадр → ffmpeg.
- `gfx.py` (рисование), `chars.py` (персонажи и пугало), `world.py` (изба, деревня), `garden.py` (огород, вид из окна, телефон).
- `ep1_render.py`, `ep2_render.py` — сцены серий.
- `build.py` — сборка «под ключ». `fonts/` — шрифты (OFL). `out/` — готовые видео. `previews/` — превью кадров.
- `models/` не входит в архив: голоса Piper скачивает `setup`, Whisper скачивается сам при первом запуске `tts.py`.

## 4. Установка и команды

**Windows:** положите папку по пути **без русских букв и пробелов**, например `C:\glukhoman`.
Установите Python 3.11 или 3.12 с python.org (галочка «Add to PATH»), затем в PowerShell:
```powershell
cd C:\glukhoman
powershell -ExecutionPolicy Bypass -File setup.ps1
python build.py ep1 --stills 1.25,44.6      # проверка: кадры в build\ep1\stills
```
**Mac / Linux:** `bash setup.sh`. На Linux для skia нужны `libegl1` и `libgl1`.

Сборка:
```
python build.py ep2 --from audio     # звук → кадры (4 процесса) → склейка → MP4 в out/ep2.mp4
python build.py ep2 --stills 1,27.5,52.6   # только превью кадров
python build.py ep1 --from audio     # пересобрать серию 1
```
Полная сборка серии на 4 ядрах занимает около 5–8 минут.

## 5. План звука для серии 2 (`ep2_audio.py`)

Берите структуру из `ep1_audio.py`: `tl = load_timeline("ep2")`, `mx = Mix(total)`, `add_voices(mx, tl, "ep2")`,
дальше слои, в конце `finish(mx, total, "ep2")`. Времена берите из `tl["cues"]` и сцен `tl["scenes"]`,
а не числами. Для справки текущие значения (сек):
title 0–4.43 · garden 4.43–11.16 (hat 7.78) · rules 11.16–19.61 (rule0 13.24, rule1 14.97, rule2 16.88) ·
days 19.61–29.05 (day1 19.61, day2 23.48, day3 25.61) · gran 29.05–33.86 · phone 33.86–38.59 (rec 33.86, play 36.54) ·
footage 38.59–53.31 (door_open 40.89, enter 43.54, stand 45.2, timelapse 47.43, turn 49.47, turn2 51.4) ·
morning 53.31–56.33 · boots 56.33–58.87 · choice 58.87–65.42 · end 65.42–67.22.

| Сцена | Звук (громкость в дБ — ориентир) |
|---|---|
| title | `crows()` в 0.05 с (−8), `wind` (−22), низкий `drone(notes=(38,45))` (−17), `sub_boom` на старте (−10) |
| garden | `birds` (−24), `wind` (−24), `music_box(beat=0.5)` (−17) до конца rules; на `hat` — `crow_caw` (−14) и мягкий `sub_boom` (−14) |
| rules | `roomtone` (−40), ходики `tick` каждые 0.5 с (−29), шкатулка продолжается, `drone` (−24) |
| days | `birds` (−26). На `day1`/`day2`/`day3`: `sub_boom` (−10 → −7 → −4) и `whoosh` (−18); на `day3` ещё `stinger(base=932)` (−11). Сердцебиение `heartbeat_one` от `day3` до конца gran (−16). Напряжённый `drone(..., dissonance=(51,0.6))` (−19) |
| gran | `roomtone`, ходики (−29), `drone` (−22) |
| phone | `crickets` (−14) до `play`; `rec_beep` на `rec`+0.3 (−12); после `play`: тихие `birds` (−30), `tap_click` на `play`+1.5 (−10) и `whoosh` (−16) |
| footage | `camera_hiss` на всю сцену (−30), еле слышные `crickets` (−32). На `door_open`: `creak(1.1)` (−10). Шаги от `enter` до `stand`+0.6 каждые 0.45 с: `straw_rustle` (−14) и `footstep_wood` (−16). На `timelapse`: `fast_forward(turn − timelapse)` (−14). Поворот головы (слово «голову»): медленный `creak` (−12), `glitch_noise` (−12). Взгляд в камеру (слово «в» в «И смотрит в камеру»): `stinger` (−8), `sub_boom` (−4), `glitch_noise` (−8). В конце сцены — резкая тишина на всех шинах, кроме голоса |
| morning | `birds` (−24), мягкий `drone` (−26) |
| boots | на слове «солома» — `straw_rustle` (−12) и `sub_boom` (−10) |
| choice | `music_box(beat=0.62, detune_drift=1.5)` (−19) и `drone` (−20); `crows` ближе к концу (−14) |
| end | `sub_boom` (−4), `stinger(base=622)` (−13) |

Время слова: `b["t0"] + b["words"][k]["s"]` у нужного бита из `tl["beats"]`.

## 6. Что важно знать

- **Озвучку нельзя послушать ушами** (у модели нет слуха), поэтому разборчивость проверяется Whisper:
  `asr_err` в `build/<ep>/voice_meta.json`, 0 — идеально. После сборки стоит прогнать Whisper по всему `mix`.
- **Неверные ударения** (espeak) правятся в `PRON_FIX` сырыми фонемами, например `(r"\b[Пп]угало", "[[pˈuɡʌɭʌ]]")`.
  Если голос бабушки плохо выговаривает слово с правкой, лучше переписать фразу.
  Так сделано с «Его не трогай» вместо «Пугало не трогай».
- Субтитры: белые — рассказчик, жёлтые — бабушка или голос за дверью, сиреневые курсивом — шёпот, красные — `*акцент*`.
- **Оригинальность:** канал вдохновлён форматом других каналов, но персонажи, истории, рисовка и звук свои.
  Не копировать чужих персонажей, названия серий и стиль.
- Нет чужой музыки: вся музыка и звуки синтезируются, поэтому TikTok не глушит звук.
- Громкость итогового ролика −14 LUFS, видео H.264 1080×1920 30 к/с, звук AAC 192k.
- Код также лежит на GitHub: репозиторий `Youpo03/miniroyale-cheats`, ветка `claude/eloquent-johnson-7203cw`,
  папка `tiktok-glukhoman`. В Git нет видео и готовой озвучки, они есть только в этом архиве.
